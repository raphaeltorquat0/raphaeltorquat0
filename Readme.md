## Raphael Torquato

Staff Software Engineer. 14+ years. Backend architecture, distributed systems, AI.

Currently part of the backend architecture team at Claro Brasil (70M+ subscribers). Apollo GraphQL Federation on AWS Lambda, 100+ API integrations, 168 business modules.

Previously built a real-time computer vision platform processing 2,000+ concurrent video streams with NVIDIA DeepStream, YOLOv8, TensorRT on bare-metal GPUs (~4000x throughput improvement).
